Tema dosyası

tw.config.json paletinizi, bileşenlerinizi, fontlarınızı ve ikonlarınızı tutar. Varsayılan temanın (ya da adını verdiği hazır görünümün) üzerine uygulanır; bu yüzden yalnızca farklı olanı içermesi yeterlidir.

{
  "version": 1,                                         // dosya biçiminin sürümü (isteğe bağlı)
  "preset": "fluent",                                   // önce uygulanır; dosyanın geri kalanı üzerine gelir
  "fontFamily": "Segoe UI",
  "spacingUnit": 4,
  "colors": {
    "brand": { "500": "#2b579a", "600": "#234a85" },   // bg-brand-500
    "canvas": "#f3f6fb"                                 // bg-canvas
  },
  "components": {
    "btn-primary": "btn bg-brand-500 text-white hover:bg-brand-600"
  }
}

Program.Main içinde, hiçbir form oluşturulmadan önce yükleyin:

TwTheme.Current = TwTheme.LoadIfExists(Path.Combine(AppDomain.CurrentDomain.BaseDirectory, "tw.config.json"));

Designer da aynı dosyayı okur: paket, proje klasöründeki tw.config.json'u uygulamanın derlemesine gömer; önizleme, bileşen ve renk listeleri temanızı kullanır (bkz. Designer).

Anahtarlar

AnahtarAnlamı
versionDosya biçiminin sürümü (TwTheme.FileVersion, şu an 1; olmayan dosya sürüm 1 sayılır). Daha yeni bir biçim için yazılmış dosya yanlış okunmak yerine reddedilir (bkz. API kararlılığı).
presettailwind, fluent, antd, material. Diğer anahtarlardan önce uygulanır.
palettev3 (varsayılan) ya da v4.
colorsYeni renkler (tek değer ya da ton rampası) ve primary, surface, danger, success, warning anlamsal rampaları.
componentsbtn-primary ya da card gibi bileşen class'ları. Bileşenler başka bileşenleri kullanabilir.
fontFamilyBir aile ya da virgülle ayrılmış bir liste; kurulu ya da kayıtlı ilk aile kullanılır.
fontsKurulmadan kaydedilecek font dosyaları.
fontWeightsBir fontun ara kalınlıklarının aileleri.
spacingUnitBir boşluk biriminin piksel değeri (varsayılan 4).
iconFont, iconsİkon fontu ve ek ikon adları (glif ya da SVG).
autoStyleAutoStyle'ın kullandığı kontrol tipi → bileşen eşlemesi.

Palet

Varsayılan palet Tailwind v3'tür: 22 renk × 11 ton (50–950), ayrıca white, black ve transparent. "palette": "v4" (kodda new TwTheme(TwPaletteVersion.V4)) aynı renklerin v4 tonlarını kullanır.

v4 renkleri OKLCH ile tanımlıdır. sRGB dışında kalanlar tarayıcılardaki gibi CSS Color 4 gamut eşlemesiyle yaklaştırılır; böylece blue-500 Tailwind sitesindeki gibi #2b7fff olur. Tema renkleri de OKLCH ile yazılabilir:

{ "colors": { "brand": "oklch(62.3% 0.214 259.8)" } }

Varsayılan bileşenler iki paletle de kontrast denetiminden geçer. Class referansı her rengi gösterir.

Fontlar

fontFamily bir liste olabilir: "Inter, Segoe UI". Uygulamayla dağıtılan fontlar kurulmadan kaydedilir; yollar tema dosyasına göredir, eksik dosyalar atlanır:

{
  "fontFamily": "Inter, Segoe UI",
  "fonts": ["Assets/fonts/Inter-Regular.ttf", "Assets/fonts/Inter-SemiBold.ttf"]
}

Kodda: TwFonts.Register(path). Fontlar hem GDI+ hem GDI'ya (sürece özel) kaydedilir; TextRenderer ile çizilen standart kontrollerde de çalışır. Fontun lisansını (örn. SIL OFL) uygulamanızla birlikte dağıtın.

Font kalınlıkları

WinForms yalnızca normal ve kalın stilleri bilir; ara kalınlıklar Windows'ta ayrı font aileleri olarak kuruludur. FormWind font-thin (100) … font-black (900) class'larını CSS'in eşleme kuralıyla bu ailelere çözer:

ClassSegoe UI'da kullanılan
font-thin, font-extralight, font-lightSegoe UI Light
font-normal, font-mediumSegoe UI
font-semiboldSegoe UI Semibold
font-boldSegoe UI + kalın stil
font-extrabold, font-blackSegoe UI Black

Başka bir font için kalınlık ailelerini tanımlayın; kurulu olmayan aile atlanır ve en yakın kurulu kalınlık seçilir:

{ "fontWeights": { "Inter": { "300": "Inter Light", "600": "Inter SemiBold" } } }

İkonlar

FormWind Windows'la gelen ikon fontunu kullanır: Windows 11'de Segoe Fluent Icons, Windows 10'da Segoe MDL2 Assets.

  • TwIcon tek başına bir ikondur. IconName Designer'da açılır listeden seçilir; renk text-*, boyut font boyutuyla verilir (text-xl = 20 × 20 px).
  • TwButton.IconName metnin yanına ikon koyar; IconPosition ve IconSpacing ayarlanabilir.
icoCustomer.IconName = "user";
tw.SetClasses(icoCustomer, "text-xl text-blue-600 dark:text-blue-400");
btnSave.IconName = "save";

Yaklaşık 80 ad yerleşiktir: save, search, settings, trash, user … (tam liste class referansında). Herhangi bir glif kod noktasıyla kullanılabilir ("#E8A5"); tema dosyası ad ekleyebilir ya da fontu değiştirebilir:

{ "iconFont": "Segoe Fluent Icons", "icons": { "invoice": "E8A5" } }

SVG ikonlar

Lucide, Heroicons ya da Tabler gibi tek renkli SVG setleri de kullanılabilir. İkon değeri bir .svg dosyasının yolu (tema dosyasına göre) ya da doğrudan <svg> metni olabilir; kodda TwTheme.SetSvgIcon(ad, svg).

"icons": {
  "invoice": "E8A5",                                    // ikon fontu glifi
  "package": "Assets/icons/package.svg",                // dosya
  "dot": "<svg viewBox='0 0 24 24'><circle cx='12' cy='12' r='4'/></svg>"
}
  • SVG ikon aynı adlı glifi ezer; böylece yerleşik ikonlar (check, chevron-down …) TwButton, TwSelect, takvim ve grid dahil her yerde değiştirilebilir.
  • Renk her zaman çizildiği yerin yazı rengidir (currentColor gibi).
  • Desteklenenler: path (yaylar dahil bütün komutlar), circle, ellipse, rect, line, polyline, polygon, g; fill, stroke, stroke-width, stroke-linecap, stroke-linejoin. Gradient, maske, metin ve CSS desteklenmez.
