Formlar ve diyaloglar

TwField ile etiket, ipucu ve hata metni; giriş maskeleri; temanızı izleyen mesaj kutuları ve bildirimler; kullanıcılarınızın dilinde metinler.

Doğrulama

var field = new TwField { LabelText = "T.C. kimlik no", Required = true, Validator = TwValidators.TcKimlikNo };
field.Controls.Add(new TwTextBox { Mask = TwMasks.TcKimlikNo });
tw.SetClasses(field, "field");                 // label:, hint: ve error: parçaları

// Kaydederken:
if (!tw.Validate(this)) return;                // hataları gösterir ve ilk geçersiz alana odaklanır
  • TwField bir etiket (zorunluysa " *"), tek bir düzenleyici ve altında ipucu ya da hata metni içerir. Kurallar: Required, Pattern (düzenli ifade), Validator (özel) ve maskeli alanlarda tamlık.
  • Etiket düzenleyicinin AccessibleName'i, hata metni AccessibleDescription'ı olur.
  • Elle hata: tw.SetError(control, "Bu ad kullanılıyor"); örneğin sunucudan gelen bir hata. Hata varken invalid: varyantı uygulanır (input bileşeni kırmızı kenarlık ve halka gösterir). Kullanıcı değeri değiştirince hata kendiliğinden temizlenir. HasErrors, ClearErrors(), ErrorsChanged.
  • Yerleşik kurallar (TwValidators): TcKimlikNo (kontrol basamakları), Iban (mod 97), Email, TurkishMobile, MinLength(n).

Maskeler

TwTextBox.Mask: 0 rakam, 9 isteğe bağlı rakam, L harf. Yalnızca uyan karakterler yazılabilir; yapıştırırken sabit karakterler atlanır.

var iban = new TwTextBox { Mask = TwMasks.Iban };
var phone = new TwTextBox { Mask = "(000) 000 00 00" };
string digits = phone.UnmaskedText;            // MaskCompleted bütün yerlerin dolduğunu söyler

Yerleşik maskeler: TwMasks.Phone, Iban, TcKimlikNo, Date, PostalCode.

Diyaloglar ve bildirimler

if (TwDialog.Show(this, "Bu sipariş silinsin mi?", "Silme onayı",
        TwDialogKind.Warning, TwDialogButtons.YesNo, danger: true) == DialogResult.Yes)
{
    DeleteOrder();
    TwToast.Show(this, "Sipariş silindi", TwDialogKind.Success);
}
  • TwDialog MessageBox'ın yerini alır: ikon, başlık, mesaj ve sağa yaslı butonlar; Enter varsayılan, Esc iptaldir. Sahip formun koyu temasını izler. Buton metinleri TwDialog.Texts[DialogResult.Yes] = "Sil" ile tek tek değiştirilir; TwDialog.Create(...) göstermeden önce özelleştirmeye izin verir.
  • TwToast sahip formun sağ alt köşesinde üst üste dizilir, odağı çalmaz, fare üzerindeyken bekler ve kendiliğinden kapanır (DefaultDuration 4 sn). Ekran okuyuculara uyarı olarak duyurulur.

Yerelleştirme

Kullanıcıya görünen metinler (diyalog butonları, doğrulama mesajları, tablonun süzme menüsü, yükleniyor metni, ekran okuyucu adları) TwTexts'tedir. Varsayılan dil İngilizcedir; uygulamanın arayüz dili (CultureInfo.CurrentUICulture) Türkçeyse Türkçe metinler seçilir.

TwTexts.Current = TwTexts.Turkish;                                                       // dili zorla
TwTexts.Current = new TwTexts { Ok = "OK", Cancel = "Abbrechen", Required = "Pflichtfeld." }; // başka bir dil
TwTexts.Current.Loading = "Veriler getiriliyor…";                                        // tek bir metin
  • Bir kontrolün kendi metin özellikleri (TwField.RequiredMessage, TwSelect.SearchPlaceholder …) atanmışsa TwTexts'in önüne geçer.
  • Biçimli metinler {0} yer tutucularını kullanır.
  • Geliştiriciye yönelik metinler (istisnalar, Designer komutları, çözümleyici uyarıları) İngilizcedir.

Sağdan sola

Bir kontrolün kalıtılan RightToLeft değeri Yes olduğunda:

  • rtl: ve ltr: varyantları Tailwind'deki gibi yöne göre uygulanır: pl-4 rtl:pl-0 rtl:pr-4.
  • Flex ve grid yerleşimleri yatayda yansıtılır, dış boşluklar da onlarla yer değiştirir.
  • TwButton, TwCheckBox, TwRadioButton, TwSwitch ve TwSelect yansıtılır.
  • Formda RightToLeftLayout = true ise pencereyi Windows yansıtır, FormWind ikinci kez yansıtmaz.

Henüz yansıtılmayanlar: TwNumberBox, TwDatePicker, TwSlider, TwProgress, TwTabStrip, TwDataList, TwTreeView, TwCalendar ve çizilen DropDownList açılır kutusu. Mantıksal ps-*/pe-* class'ları yoktur; rtl: kullanın.
