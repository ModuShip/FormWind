Başlarken

FormWind elinizdeki WinForms kontrollerini stiller. Paketi ekleyin, temayı yükleyin, forma bir TailwindProvider bırakın; sonra işi AutoStyle'a bırakın ya da kontrol başına class yazın.

Gereksinimler

  • .NET Framework 4.7.2+ ya da .NET 8+ (net472, net8.0-windows). Testler .NET 9 ve 10'da da çalışır.
  • .NET dışında bağımlılık yoktur (net472 için yalnızca System.Text.Json).
  • Koyu başlık çubukları ve native koyu kaydırma çubukları için Windows 10 ya da sonrası; sistem zeminleri ve Segoe Fluent Icons için Windows 11.

Önizleme

FormWind 0.1 bir önizleme sürümüdür: paketler NuGet'te ön sürüm olarak yayımlanır (--prerelease ile kurun) ve 1.0'a kadar ara sürümler kırıcı değişiklik içerebilir.

Kurulum

dotnet add package FormWind --prerelease

Krypton Toolkit kullanan uygulamalara ayrıca FormWind.Krypton paketini ekleyin (bkz. Krypton Toolkit).

İlk formunuzu stilleyin

  1. Temayı yükleyin. Program.Main içinde, hiçbir form oluşturulmadan önce. Dosya yoksa varsayılan tema kullanılır.

    TwTheme.Current = TwTheme.LoadIfExists(
    Path.Combine(AppDomain.CurrentDomain.BaseDirectory, "tw.config.json"));

  2. Bir TailwindProvider ekleyin. Toolbox'tan forma sürükleyin. Listede yoksa: Toolbox → sağ tık → Choose Items → FormWind.dll.

  3. Yolunuzu seçin. Her kontrolü tipine göre stillemek için AutoStyle'ı açın ya da bir kontrol seçip Classes on tailwindProvider1 alanını doldurun. Designer şunu yazar:

    this.tailwindProvider1.SetClasses(this.btnSave, "btn-primary");

  4. Koyu temayı açın. İstediğiniz an; bütün dark: varyantları birlikte uygulanır:

    tailwindProvider1.DarkMode = true;

Designer olmadan

Kodla kurulan formlar da aynı şekilde çalışır. AutoStyle kullanırken ContainerControl'ü kendiniz atayın:

public sealed class MainForm : Form
{
    private readonly TailwindProvider _tw = new TailwindProvider();

    public MainForm()
    {
        SuspendLayout();
        AutoScaleMode = AutoScaleMode.Dpi;
        AutoScaleDimensions = new SizeF(96F, 96F);

        var save = new TwButton { Text = "Kaydet", IconName = "save", Size = new Size(120, 36) };
        var card = new TwPanel { Size = new Size(360, 200) };
        card.Controls.Add(save);
        Controls.Add(card);

        _tw.ContainerControl = this;
        _tw.AutoStyle = true;                       // her kontrol kendi bileşenini alır
        _tw.SetClasses(card, "card flex flex-col gap-3 p-6");
        _tw.SetClasses(save, "btn-primary");        // kendi bileşeni AutoStyle'ın önüne geçer
        ResumeLayout();
    }
}

Proje şablonu

FormWind.Templates hazır ekranlarla bir uygulama oluşturur: doğrulamalı alanlarla giriş, aranabilir TwDataList ile liste–detay ve ayarlar. Açık/koyu tema anahtarı formlar arasında paylaşılır. Şablon metinleri İngilizcedir.

dotnet new install FormWind.Templates
dotnet new formwind-app -n MyApp --Framework net8.0-windows --Preset fluent --Krypton true
SeçenekDeğerler
--Frameworknet8.0-windows (varsayılan), net9.0-windows, net10.0-windows, net472
--Presettailwind (varsayılan), fluent, antd, material
--Palettev3 (varsayılan), v4
--Kryptontrue: FormWind.Krypton paketini ekler, KryptonApplier'ı kaydeder ve Krypton paletini ana formun temasına bağlar
--FormWindVersionPaket sürümü (varsayılan: şablon paketinin sürümü)

Şablondaki formlar kodla kurulur ve AutoScaleMode.Dpi kullanır.

Önce mevcut bir uygulamada deneyin

Harness, bir .NET WinForms uygulamasını kaynak koduna dokunmadan her forma FormWind uygulanmış olarak çalıştırır; kontrast sorunlarını, donmaları ve tanınmayan kontrolleri raporlar.

.\tools\run-harness.ps1 -Exe C:\apps\MyApp.exe -SelfTest -ExitAfter 60

Sırada ne var?

Hazır görünümler ve AutoStyleBütün uygulamayı class yazmadan stilleyin. Class'larRenkler, boşluklar, kenarlıklar, varyantlar. YerleşimTwPanel üzerinde flex ve grid. DataGridViewParçalar, hücre tipleri ve süzmeli tablolar.
