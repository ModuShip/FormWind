Controls

Colors, text and spacing work on every standard control. Where a native control can't be styled well — rounded text boxes, owner-drawn lists, a stylable drop-down — FormWind adds a Tw* control.

Control catalog

TwPanelA card with smooth corners and borders; the host for flex and grid.
TwTextBoxA borderless TextBox in a rounded panel, with PlaceholderText and masks.

Standard controls

A TextBox gets its border-* and rounded-* as a frame on its parent. A ComboBox in DropDownList mode has its closed box painted by FormWind — background, border, corners, text and arrow; the drop-down list stays native. Editable combo boxes and ListBox get colors and fonts but no corners; use TwSelect and TwListBox for those.

TwDataList

A virtual list: rows are requested by index and only visible rows are drawn, so drawing time does not depend on the item count.

list.ItemCount = orders.Count;
list.ItemHeight = 52;                       // 96 DPI pixels
list.DrawItem += (s, e) =>
{
    var o = orders[e.Index];
    var c = e.ContentBounds;
    int left = e.DrawBadge(o.Status, c.Right, badgeBack, badgeFore);
    e.DrawText(o.Customer, new Rectangle(c.X, c.Y + 6, left - c.X - 12, 20), font: e.FontWithWeight(600));
    e.DrawText(o.Number, new Rectangle(c.X, c.Y + 26, left - c.X - 12, 20), e.MutedColor);
};
tw.SetClasses(list, "p-1 bg-white text-gray-900 item:hover:bg-gray-100 selected:bg-blue-50 selected:text-blue-900 "
                  + "row:border-gray-100 fill-gray-300 dark:bg-gray-800 dark:text-gray-100 dark:selected:bg-blue-950");
  • Without DrawItem, ItemText (or the index) is drawn as one line.
  • Smooth wheel scrolling; an owner-drawn scrollbar colored with fill-*. ↑/↓, PageUp/PageDown, Home/End; Enter and double-click raise ItemActivate.
  • Multi-selection with SelectionMode = MultiExtended: Ctrl+click, Shift+click, Shift+arrows, Ctrl+A — without storing indices, even with a million rows.
  • Groups: SetGroups(new[] { (0, "Today"), (12, "Yesterday") }); the current header sticks while scrolling.
  • Variable heights: ItemHeights = i => orders[i].HasNote ? 72 : 52.
  • Incremental loading: IsItemLoaded draws skeleton rows and ItemsNeeded(first, last) asks for the visible range.

Menus and toolbars

MenuStrip, ToolStrip, StatusStrip and ContextMenuStrip get a themed renderer. Base classes style the strip, menu: the drop-down menus and item: the items:

tw.SetClasses(menuStrip1, "bg-white text-gray-700 border-b menu:bg-white menu:border-gray-200 "
    + "item:hover:bg-gray-100 item:rounded-md divide-gray-200 dark:bg-gray-900 dark:text-gray-200");
  • On a dark strip, the hover, separator and menu-border defaults are derived from the strip's own colors, so text never disappears in the hover box.
  • Drop-downs assigned by hand (menuItem.DropDown = contextMenuStrip1) get the strip's renderer too, nested ones included.
  • Removing the classes restores the strip's original renderer.

Title bar and backdrop

When a form has classes and dark mode is on, its title bar turns dark (Windows 10 20H1+). On Windows 11, caption:bg-*, caption:text-* and caption:border-* color it.

backdrop-mica, backdrop-acrylic, backdrop-tabbed and backdrop-none pick the Windows 11 22H2+ system backdrop for the title bar and window frame.

tw.SetClasses(this, "page caption:bg-white dark:caption:bg-gray-900 backdrop-mica");

Dark native parts

With DarkMode = true, the parts FormWind doesn't draw switch to Windows' dark theme too:

Property (on by default)Effect
DarkScrollbarsScrollbars of panels, text boxes, list boxes, tree views, list views and grids.
DarkToolTipsNative tooltips: ToolTip components, ToolStrip item tips, ListView/TreeView tips.

Both use the undocumented DarkMode_Explorer theme (Windows 10 1809+) and do nothing on systems that don't support it.
