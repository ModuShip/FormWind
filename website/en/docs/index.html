Getting started

FormWind styles the WinForms controls you already have. Add the package, load a theme, drop a TailwindProvider on a form — and either let AutoStyle do the work or write classes per control.

Requirements

  • .NET Framework 4.7.2+ or .NET 8+ (net472, net8.0-windows). Tests also run on .NET 9 and 10.
  • No dependencies beyond .NET (only System.Text.Json on net472).
  • Windows 10 or later for dark title bars and native dark scrollbars; Windows 11 for backdrops and Segoe Fluent Icons.

Preview

FormWind 0.1 is a preview: the packages are on NuGet as prereleases (install with --prerelease), and minor versions may contain breaking changes until 1.0.

Install

dotnet add package FormWind --prerelease

For Krypton Toolkit applications, add FormWind.Krypton as well (see Krypton Toolkit).

Style your first form

  1. Load the theme in Program.Main, before any form is created. If the file does not exist, the default theme is used.

    TwTheme.Current = TwTheme.LoadIfExists(
    Path.Combine(AppDomain.CurrentDomain.BaseDirectory, "tw.config.json"));

  2. Add a TailwindProvider to the form from the Toolbox. If it is not listed: Toolbox → right-click → Choose Items → FormWind.dll.

  3. Pick a path. Turn on AutoStyle to style every control by its type, or select a control and fill in Classes on tailwindProvider1. The Designer writes:

    this.tailwindProvider1.SetClasses(this.btnSave, "btn-primary");

  4. Turn on dark mode whenever you like — all dark: variants apply at once:

    tailwindProvider1.DarkMode = true;

Without the Designer

Forms built in code work the same way. Set ContainerControl yourself when you use AutoStyle:

public sealed class MainForm : Form
{
    private readonly TailwindProvider _tw = new TailwindProvider();

    public MainForm()
    {
        SuspendLayout();
        AutoScaleMode = AutoScaleMode.Dpi;
        AutoScaleDimensions = new SizeF(96F, 96F);

        var save = new TwButton { Text = "Save", IconName = "save", Size = new Size(120, 36) };
        var card = new TwPanel { Size = new Size(360, 200) };
        card.Controls.Add(save);
        Controls.Add(card);

        _tw.ContainerControl = this;
        _tw.AutoStyle = true;                       // every control gets its component
        _tw.SetClasses(card, "card flex flex-col gap-3 p-6");
        _tw.SetClasses(save, "btn-primary");        // own component wins over AutoStyle
        ResumeLayout();
    }
}

Project template

FormWind.Templates creates an application with ready-made screens: sign-in with validated fields, a list-detail screen with a searchable TwDataList, and settings. The light/dark switch is shared across forms.

dotnet new install FormWind.Templates
dotnet new formwind-app -n MyApp --Framework net8.0-windows --Preset fluent --Krypton true
OptionValues
--Frameworknet8.0-windows (default), net9.0-windows, net10.0-windows, net472
--Presettailwind (default), fluent, antd, material
--Palettev3 (default), v4
--Kryptontrue adds FormWind.Krypton, registers KryptonApplier and binds the Krypton palette to the main form's theme
--FormWindVersionPackage version (default: the template package's version)

Template forms are built in code and use AutoScaleMode.Dpi.

Try it on an existing app first

The harness runs a .NET WinForms application with FormWind applied to every form — without changing its source — and reports contrast problems, stalls and unknown controls.

.\tools\run-harness.ps1 -Exe C:\apps\MyApp.exe -SelfTest -ExitAfter 60
