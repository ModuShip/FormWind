Krypton and other libraries

FormWind.Krypton works in Krypton Toolkit applications in two ways, which can be combined: a theme bridge that needs no classes, and classes on individual Krypton controls.

dotnet add package FormWind.Krypton --prerelease

Theme bridge

TwKryptonTheme builds a Krypton palette from the FormWind theme and makes it Krypton's global palette. Every Krypton control without classes follows the chosen preset and dark mode.

using FormWind.Krypton;

KryptonApplier.Register();                                  // in Program.Main
var palette = TwKryptonTheme.Follow(tailwindProvider1);     // in the main form; Dispose() when it closes

The palette is rebuilt when the theme changes or DarkMode is toggled. It starts from Krypton's Microsoft 365 White (light) or Black (dark) palette; parts FormWind doesn't map — ribbon, navigator tabs, Krypton's menus — keep those colors. To manage a fixed palette yourself, TwKryptonTheme.CreatePalette(theme, dark) returns a KryptonCustomPaletteBase.

Classes on Krypton controls

KryptonApplier writes classes to Krypton's state palettes: base → StateCommon, hover: → StateTracking, active: → StatePressed, focus: → OverrideFocus (StateActive for input controls), disabled: → StateDisabled, checked: → StateChecked*.

Versions

FormWind.Krypton is built against Krypton Toolkit 100.25.11.328 (the package depends on that version or later), and CI tests it with 105.26.7.201 as well. .NET Framework applications that use a newer Krypton need binding redirects; SDK-style projects generate them.

The sample samples/FormWind.Krypton.Showcase has a preset picker (--preset material, --dark). In the template: dotnet new formwind-app --Krypton true.

Other control libraries

Libraries with their own skin engine paint their controls themselves. FormWind's standard applier handles controls it doesn't recognize: size, spacing and layout usually work, while colors, state variants and corners may conflict with the library's painting. Three ways to combine them:

  • Side by side. Keep the library's strengths — advanced grids, ribbons, schedulers — on its engine, and use FormWind for standard controls, new screens and the form skeleton. Library controls can be items in a TwPanel flex or grid layout.
  • Write an applier. Implement IStyleApplier, register it with TwAppliers.Register and map the base style and each variant to the library's appearance objects. The Krypton integration is an example. For grids derived from DataGridView, TwAppliers.FindBuiltIn hands structural styling to FormWind.
  • Theme sync only. Give the library's controls no classes; switch its light/dark skin when DarkModeChanged fires, and optionally carry your tw.config.json colors into its palette.

.NET 9+ color mode

On .NET 9 and later, Application.SetColorMode(SystemColorMode.Dark) darkens system colors and native controls. FormWind works with it: class colors take precedence, and removing classes returns a control to the dark system color. Bind DarkMode to the application's mode for dark: variants:

tw.DarkMode = Application.IsDarkModeEnabled;
