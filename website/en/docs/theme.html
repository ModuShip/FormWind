Theme file

tw.config.json holds your palette, components, fonts and icons. It is applied on top of the default theme — or on top of the preset it names — so it only needs what is different.

{
  "preset": "fluent",                                   // applied first; the rest goes on top
  "fontFamily": "Segoe UI",
  "spacingUnit": 4,
  "colors": {
    "brand": { "500": "#2b579a", "600": "#234a85" },   // bg-brand-500
    "canvas": "#f3f6fb"                                 // bg-canvas
  },
  "components": {
    "btn-primary": "btn bg-brand-500 text-white hover:bg-brand-600"
  }
}

Load it in Program.Main before any form is created:

TwTheme.Current = TwTheme.LoadIfExists(Path.Combine(AppDomain.CurrentDomain.BaseDirectory, "tw.config.json"));

The Designer reads the same file: the package embeds tw.config.json from the project folder into the application's assembly, so the preview and the component and color lists use your theme (see Designer).

Keys

KeyMeaning
presettailwind, fluent, antd, material. Applied before the other keys.

fontsFont files to register without installing them.

autoStyleControl type → component map used by AutoStyle.

Palette

The default palette is Tailwind v3: 22 colors × 11 shades (50–950), plus white, black and transparent. "palette": "v4" (in code new TwTheme(TwPaletteVersion.V4)) uses the v4 shades of the same colors.

v4 colors are defined in OKLCH. Colors outside sRGB are approximated with CSS Color 4 gamut mapping, as browsers do, so blue-500 is #2b7fff just like on the Tailwind site. Theme colors can be written in OKLCH as well:

{ "colors": { "brand": "oklch(62.3% 0.214 259.8)" } }

The default components pass the contrast audit with both palettes. The class reference shows every swatch.

Fonts

fontFamily can be a stack: "Inter, Segoe UI". Fonts shipped with the application are registered without installation; paths are relative to the theme file and missing files are skipped:

{
  "fontFamily": "Inter, Segoe UI",
  "fonts": ["Assets/fonts/Inter-Regular.ttf", "Assets/fonts/Inter-SemiBold.ttf"]
}

In code: TwFonts.Register(path). Fonts are registered with both GDI+ and GDI (process-private), so they work in standard controls drawn with TextRenderer too. Distribute the font's license (e.g. SIL OFL) with your application.

Font weights

WinForms only knows regular and bold; intermediate weights are installed on Windows as separate families. FormWind resolves font-thin (100) … font-black (900) to these families with CSS's matching rules:

ClassUsed with Segoe UI
font-thin, font-extralight, font-lightSegoe UI Light
font-normal, font-mediumSegoe UI
font-semiboldSegoe UI Semibold
font-boldSegoe UI + bold style
font-extrabold, font-blackSegoe UI Black

For another font, map its weight families; a family that is not installed is skipped and the closest installed weight is used:

{ "fontWeights": { "Inter": { "300": "Inter Light", "600": "Inter SemiBold" } } }

Icons

FormWind uses the icon font that ships with Windows: Segoe Fluent Icons on Windows 11, Segoe MDL2 Assets on Windows 10.

  • TwIcon is a standalone icon. Pick IconName from a drop-down in the Designer; color with text-*, size with the font size (text-xl = 20 × 20 px).
  • TwButton.IconName puts an icon next to the text, with IconPosition and IconSpacing.
icoCustomer.IconName = "user";
tw.SetClasses(icoCustomer, "text-xl text-blue-600 dark:text-blue-400");
btnSave.IconName = "save";

About 80 names are built in — save, search, settings, trash, user … (the class reference lists them all). Any glyph can be used by code point ("#E8A5"), and the theme file adds names or switches the font:

{ "iconFont": "Segoe Fluent Icons", "icons": { "invoice": "E8A5" } }

SVG icons

Single-color SVG sets such as Lucide, Heroicons or Tabler work too. An icon value can be a path to an .svg file (relative to the theme file) or inline <svg> markup; in code, TwTheme.SetSvgIcon(name, svg).

"icons": {
  "invoice": "E8A5",                                    // glyph from the icon font
  "package": "Assets/icons/package.svg",                // file
  "dot": "<svg viewBox='0 0 24 24'><circle cx='12' cy='12' r='4'/></svg>"
}
  • An SVG icon overrides the glyph of the same name, so built-in icons (check, chevron-down …) can be replaced everywhere — in TwButton, TwSelect, the calendar and the grid.
  • The color is always the text color where it is drawn, like currentColor.
  • Supported: path (all commands, arcs included), circle, ellipse, rect, line, polyline, polygon, g; fill, stroke, stroke-width, stroke-linecap, stroke-linejoin. Gradients, masks, text and CSS are not.
