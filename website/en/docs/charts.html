Charts

Lightweight charts with no extra dependency: TwChart (line, area, bar), TwDonutChart, TwSparkline the KPI card TwStat, and the analytics controls TwHeatmap, TwRingChart, TwTimeline and TwStepper. They follow the theme, dark mode and DPI like the other controls; with AutoStyle they get the chart and stat components.

Run it from the sample: FormWind.Showcase --charts (clicking a month, quarter or slice updates the status line through ItemClick).

Line, area and bar

chart.Kind = TwChartKind.Bar;                    // Line, Area, Bar; Stacked = true stacks the bars
chart.SetData(new[] { "Jan", "Feb", "Mar" },
    new TwChartSeries("Revenue", new[] { 120.0, 150, 170 }),
    new TwChartSeries("Target", new[] { 130.0, 140, 160 }) { Kind = TwChartKind.Line });
chart.ValueFormat = "C0";                        // tooltip; axis ticks are compact (1.2K) unless AxisFormat is set
  • One value axis; bar and area charts include zero. double.NaN is a missing value and leaves a gap in the line.
  • Bars are at most 24 px wide with a rounded end, 2 px apart; lines are 2 px; areas are a 10% wash; markers only on the last point and the highlighted category.
  • A legend is shown for two or more series (ShowLegend); its key has the series' mark.

Secondary axis, targets and markers

A series on TwChartAxis.Secondary gets its own scale on the right: a Pareto chart shows counts as bars and the cumulative share as a line. ReferenceLines mark targets and thresholds, Markers mark a category such as "Today", and dashed series show projections.

var pareto = new TwChart { Kind = TwChartKind.Bar, MaxBarWidth = 48, SecondaryAxisFormat = "0'%'" };
pareto.SetData(causes,
    new TwChartSeries("Minutes", minutes) { ShowValues = true },
    new TwChartSeries("Cumulative %", cumulative) { Kind = TwChartKind.Line, Axis = TwChartAxis.Secondary });
pareto.ReferenceLines.Add(new TwChartReferenceLine(80, "80%") { Axis = TwChartAxis.Secondary });

projection.SetData(weeks,
    new TwChartSeries("Actual", actual),
    new TwChartSeries("Without action", forecast) { Dashed = true, ShowValues = true });
projection.Markers.Add(new TwChartMarker(3, "Today"));

The secondary axis has its own SecondaryAxisMinimum, SecondaryAxisMaximum and SecondaryAxisInterval.

Donut

donut.SetData(new[] { "Web", "Store", "Phone" }, new[] { 52.0, 28, 20 });
donut.CenterLabel = "Orders";                    // the total is shown in the middle by default

The legend sits beside the ring when there is room, otherwise below it, with each slice's value and share. Slices past eight are folded into "Other".

Sparklines and KPI cards

spark.Values = new[] { 3.0, 5, 4, 8 };           // Kind: Line, Area, Bar

stat.Title = "Revenue"; stat.Value = "$1.24M"; stat.Delta = 0.124; stat.Caption = "vs last month";
stat.Trend = new[] { 820.0, 940, 910, 1040, 1240 };
stat.PositiveIsGood = false;                     // costs, error rates: a rise is red

The change uses the theme's success and danger colors and always carries an arrow and a sign.

Analytics controls

The downtime dashboard in the sample uses all of them: FormWind.Showcase --downtime.

Heatmap

TwHeatmap shades a grid of cells (lines against days, machines against hours) from LowColor to HighColor, by default from one step off the surface to accent-*. When the values cross zero, as in a correlation matrix, the scale diverges toward NegativeColor. double.NaN leaves a cell empty.

heat.Maximum = 120; heat.LegendMinText = "0"; heat.LegendMaxText = "120+ min";
heat.SetData(new[] { "Line 1", "Line 2" }, new[] { "Mon", "Tue", "Wed" },
    new double[,] { { 12, 40, 8 }, { 0, 95, 30 } });
heat.CellClick += (s, e) => status.Text = heat.GetItemText(e.Row, e.Column);

corr.ShowValues = true; corr.ValueFormat = "0.00"; corr.Minimum = -1; corr.Maximum = 1;   // correlation matrix

Progress rings

TwRingChart draws concentric rings, outermost first, around a large center text: a single completion ring ("6/9"), or the parts of a product such as OEE = availability × performance × quality. Each ring fills clockwise over a divide-* track; with two or more rings a legend lists the values.

rings.CenterText = "71.4"; rings.CenterLabel = "OEE %";
rings.SetData(("Availability", 82.1), ("Performance", 91.3), ("Quality", 95.2));   // out of 100; TwChartRing sets another maximum

Timeline

TwTimeline places events on a time axis, each dot sized by its value, with the date above and the value below. It shows how often something recurs and whether the gaps shrink.

timeline.ValueFormat = "0 'min'";
timeline.Items.Add(new TwTimelineEvent(new DateTime(2026, 9, 17), 22, "DR-24410"));
timeline.Items.Add(new TwTimelineEvent(new DateTime(2026, 9, 26), 31, "DR-24533"));

Stepper

TwStepper shows a flow such as an approval chain: Vertical (with descriptions and badges), Horizontal (compact chips) or Segments. Each TwStep is Pending, Current, Completed or Error.

flow.Steps.Add(new TwStep("Operator entry", description: "draft 00:05") { Badge = "In progress" });
flow.Steps.Add(new TwStep("Supervisor approval"));
flow.Steps.Add(new TwStep("Maintenance sign-off"));
flow.SetCurrent(0);

chips.Variant = TwStepperVariant.Horizontal;
chips.Steps.Add(new TwStep("Entered", TwStepStatus.Completed, "18:55"));

Like the charts, these controls highlight an item on hover or with the arrow keys, and expose one item per cell, ring, event or step to screen readers.

Classes

ClassEffect
bg-*, text-*, fontBackground, values and legend text, font
label:text-*Axis labels, secondary legend text, titles and captions
divide-*Gridlines
accent-*The first series and sparklines

Series take a fixed, validated palette in order (readable with color-vision deficiencies, separate light and dark steps) and keep their color when others are added or removed; set TwChartSeries.Color to choose one.

Keyboard and screen readers

  • Hover or the arrow keys (Home/End) highlight a category or slice and show its values; Enter or a click raises ItemClick.
  • Charts have the Chart role with one item per category or slice, e.g. "Mar: Revenue 170, Target 160".
