Layout

A TwPanel with the flex or grid class lays out its children itself, with a subset of CSS flexbox and grid.

// Card: vertical stack, items fill the width
tw.SetClasses(pnlCard, "card flex flex-col gap-1");
// Button row: right-aligned, 8 px apart
tw.SetClasses(pnlActions, "flex justify-end gap-2");
// Spacer: takes the remaining space and pushes the button row down
tw.SetClasses(pnlSpacer, "flex-1");

Inside a flex or grid panel the children's Location, Dock and Anchor are ignored. The layout engine of the standard Panel and Form cannot be replaced, so flex and grid only work on TwPanel — or on a container that implements ITwLayoutHost.

A form in grid

tw.SetClasses(pnlForm, "grid grid-cols-2 gap-x-4 gap-y-3 p-6");
tw.SetClasses(fldName, "field col-span-2");
tw.SetClasses(fldCity, "field");
tw.SetClasses(fldDate, "field");
tw.SetClasses(pnlActions, "col-span-2 flex justify-end gap-2");

Differences from CSS

  • An item's natural size is its Size from the Designer (the preferred size for AutoSize controls). Items without a size class do not shrink below it.
  • Spacing between items comes only from m-*; WinForms' default 3 px Margin is ignored.
  • The default is items-stretch: items in a row stretch to the container's height, items in a column to its width.
  • Grid items are placed in order with CSS's auto-placement; cells covered by row-span-* are skipped. grid-rows-N divides the height into N equal rows. There is no col-start-*, row-start-*, grid-flow-*, margin: auto or order-*.
  • Items do not overflow the row's cross size (WinForms would clip them); shrinking labels show "…" with truncate.
  • Content starts inside the panel's border, as in the CSS box model. With AutoScroll, room for the vertical scrollbar is reserved.
  • A flex TwPanel with AutoSize = true sizes to its content (not yet for grid).
  • In right-to-left forms layouts are mirrored, as with CSS dir="rtl".

Responsive variants

sm:, md:, lg:, xl: and 2xl: apply by the form's client width — 640, 768, 1024, 1280 and 1536 px at 96 DPI, configurable through TwBreakpoints. When the form is resized across a threshold, only controls that use these variants are restyled.

tw.SetClasses(pnlForm, "flex flex-col gap-4 md:flex-row lg:gap-8");
tw.SetClasses(lblTitle, "text-lg lg:text-2xl");

Animations

The tab indicator slides to the new tab, list row hovers fade in and skeleton rows pulse gently. TwMotion.Enabled follows Windows' "Show animations" setting and can be turned off in code. Nothing animates at design time or while invisible.
