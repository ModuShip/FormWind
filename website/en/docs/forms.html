Forms and dialogs

Labels, hints and errors with TwField; input masks; message boxes and toasts that follow your theme; texts in your users' language.

Validation

var field = new TwField { LabelText = "Email", Required = true, Validator = TwValidators.Email };
field.Controls.Add(new TwTextBox());
tw.SetClasses(field, "field");                 // label:, hint: and error: parts

// On save:
if (!tw.Validate(this)) return;                // shows the errors and focuses the first invalid field
  • TwField holds a label (" *" when required), one editor and a hint or error below it. Rules: Required, Pattern (regular expression), Validator (custom), and completeness for masked fields.
  • The label becomes the editor's AccessibleName and the error its AccessibleDescription.
  • Manual errors: tw.SetError(control, "Already taken") — from a server, say. While an error is set the invalid: variant applies (the input component shows a red border and ring). It clears when the user changes the value. HasErrors, ClearErrors(), ErrorsChanged.
  • Built-in rules (TwValidators): Email, Iban (mod 97), MinLength(n), TcKimlikNo (Turkish national ID), TurkishMobile.

Masks

TwTextBox.Mask: 0 digit, 9 optional digit, L letter. Only matching characters can be typed; pasting skips literal characters.

var iban = new TwTextBox { Mask = TwMasks.Iban };
var phone = new TwTextBox { Mask = "(000) 000 00 00" };
string digits = phone.UnmaskedText;            // MaskCompleted tells whether every slot is filled

Built-in masks: TwMasks.Phone, Iban, TcKimlikNo, Date, PostalCode.

Dialogs and toasts

if (TwDialog.Show(this, "Delete this order?", "Confirm delete",
        TwDialogKind.Warning, TwDialogButtons.YesNo, danger: true) == DialogResult.Yes)
{
    DeleteOrder();
    TwToast.Show(this, "Order deleted", TwDialogKind.Success);
}
  • TwDialog replaces MessageBox: icon, title, message and right-aligned buttons; Enter is the default and Esc cancels. It follows the owner form's dark mode. Override button texts with TwDialog.Texts[DialogResult.Yes] = "Delete", or customize with TwDialog.Create(...) before showing.
  • TwToast stacks in the bottom-right corner of the owner form, doesn't steal focus, pauses while hovered and closes itself (DefaultDuration 4 s). Screen readers announce it as an alert.

Localization

User-facing texts — dialog buttons, validation messages, the grid's filter menu, loading text, screen reader names — live in TwTexts. English is the default; Turkish is chosen when CultureInfo.CurrentUICulture is Turkish.

TwTexts.Current = TwTexts.Turkish;                                                       // force a language
TwTexts.Current = new TwTexts { Ok = "OK", Cancel = "Abbrechen", Required = "Pflichtfeld." }; // another language
TwTexts.Current.Loading = "Fetching data…";                                              // a single text
  • A control's own text properties (TwField.RequiredMessage, TwSelect.SearchPlaceholder …) win over TwTexts when set.
  • Formatted texts use {0} placeholders.
  • Developer-facing texts — exceptions, Designer commands, analyzer warnings — are in English.

Right-to-left

When a control's inherited RightToLeft is Yes:

  • rtl: and ltr: variants apply by direction, as in Tailwind: pl-4 rtl:pl-0 rtl:pr-4.
  • Flex and grid layouts mirror horizontally, and margins swap with them.
  • TwButton, TwCheckBox, TwRadioButton, TwSwitch and TwSelect mirror.
  • With RightToLeftLayout = true Windows mirrors the window itself and FormWind does not mirror again.

Not mirrored yet: TwNumberBox, TwDatePicker, TwSlider, TwProgress, TwTabStrip, TwDataList, TwTreeView, TwCalendar and the painted DropDownList combo box. There are no logical ps-*/pe-* classes; use rtl:.
