Modern WinForms, without the rewrite.

FormWind is a Tailwind-style styling layer for the controls you already have. Pick a preset, turn on AutoStyle, and your forms get a modern look and dark mode — then refine any control with utility classes.

Three ways in

Start without classes. Add them where you need them.

Your controls, events and Designer files stay as they are. FormWind only changes how they look.

1

Preset + AutoStyle

Choose Tailwind, Fluent, Ant Design or Material. Every button, text box, list and grid on the form gets the matching component — no classes written.

// tw.config.json: { "preset": "fluent" }
tailwindProvider1.AutoStyle = true;
tailwindProvider1.DarkMode = true;
2

Classes per control

Drop a TailwindProvider on a form and every control gets a Classes property, with a class builder in its smart tag.

tw.SetClasses(btnSave, "btn-primary");
tw.SetClasses(pnlCard, "card flex flex-col gap-2");
tw.SetClasses(lblHint, "text-sm text-gray-500");
3

Krypton bridge

Already on Krypton Toolkit? Its palette follows the FormWind preset and dark mode. Ribbon, docking and navigator stay in place.

KryptonApplier.Register();
var palette = TwKryptonTheme.Follow(tailwindProvider1);

Presets

One set of component names. Four looks.

Every preset defines the same components — btn-primary, input, card, table … — so switching looks restyles the whole application without touching a class.

Tailwind

The default. Tailwind's v3 palette (or v4, OKLCH-mapped to sRGB), Segoe UI and soft rounded corners.

{ "preset": "tailwind", "palette": "v4" }

Fluent

Inspired by Windows 11: Segoe UI Variable where available, small radii and a calm neutral surface.

{ "preset": "fluent" }

Ant Design

Inspired by Ant Design — with its primary blue darkened where white text would fall below WCAG AA.

{ "preset": "antd" }

Material

Inspired by Material Design: Roboto when installed, pill buttons and filled inputs.

{ "preset": "material" }

Features

What a modern UI needs, on the controls you already ship.

State variants

hover:, focus-visible:, active:, disabled:, checked:, invalid:, dark: and their combinations, with color transitions.

Flex and grid

flex, gap-4, justify-between, grid-cols-3, col-span-2 and responsive md: variants on TwPanel.

Dark mode all the way

Title bars, native scrollbars, tooltips, menus and the MDI area turn dark too — not just the controls you styled.

DataGridView

Header, row, cell and selection parts; badge, avatar, progress and button columns; sorting, filtering, paging and virtual rows.

Accessible by default

UI Automation trees for owner-drawn controls, a WCAG contrast audit, Windows High Contrast and forced-colors:.

Designer support

A Classes property, a class builder and component picker in the smart tag, and a live preview using your project's theme — in the .NET 8+ Designer too.

Owner-drawn controls

TwButton, TwTextBox, TwSelect, TwDatePicker, TwDataList, TwTreeView, TwSwitch and more, with anti-aliased corners.

Safe to adopt

Styling errors never crash the host, colors your code assigns are kept, and removing classes restores the original values.

Tooling

A converter that turns hard-coded Designer colors into classes, a harness for trying real apps unchanged, and two Roslyn analyzers.

Krypton Toolkit

Bring your Krypton UI along.

FormWind.Krypton builds a Krypton palette from the FormWind theme, so every Krypton control follows the chosen preset and dark mode — without a single class.

  • Classes on Krypton controls map to their state palettes: hover: → tracking, active: → pressed, checked: → checked.
  • KryptonDataGridView, combo boxes, group boxes, header groups, list boxes and KryptonForm captions.
  • Tested against Krypton Toolkit 100.25 and 105.26.

Krypton integration →

Migration

Already have hand-tuned colors? Convert them.

The converter reads your C# and Visual Basic Designer files and replaces hard-coded colors, fonts, padding and flat-button settings with classes — matched to the nearest palette color, with a report of everything it left alone.

Verified on Git Extensions and Greenshot: the converted projects built without warnings and rendered the same colors and fonts.
